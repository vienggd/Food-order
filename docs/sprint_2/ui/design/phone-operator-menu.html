Operator: menu management (phone)

Route /operator/menu (new, F-05). Operators see every item, add items, edit name and price, and switch "Sold out" on or off. Rules: name 1–60 characters and unique (BR-08), price ฿0.01–฿1,000.00 stored as whole satang (BR-09), sold out affects new orders only (BR-10).

Item list

GET /api/operator/menu (includes sold-out items). The switch saves at once with PATCH /api/operator/menu/:id { isAvailable }.
